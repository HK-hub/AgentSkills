# AgentSkills

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](./LICENSE)
[![GitHub stars](https://img.shields.io/github/stars/HK-hub/AgentSkills?style=social)](https://github.com/HK-hub/AgentSkills/stargazers)
[![Last commit](https://img.shields.io/github/last-commit/HK-hub/AgentSkills)](https://github.com/HK-hub/AgentSkills/commits/main)

精选的 **279 个 Agent Skills** 合集，面向真实工程、设计与创意工作流。

每个一级目录都是一个独立 Skill，包含 `SKILL.md` 入口文件（以及可选的
`references/`、`scripts/`、`examples/`、`assets/` 目录）。

## 安装

使用 [npx skills](https://www.npmjs.com/package/skills) 命令行工具安装。

> **注意：** 安装**单个** Skill 的正确语法是 `-s <skill-name>`，技能名称作为
> `-s` 参数传入，而不是追加在仓库名后面。

### 安装全部 Skills（完整合集）

```bash
npx skills add HK-hub/AgentSkills
```

非交互式安装**全部** Skills（跳过选择提示）：

```bash
npx skills add HK-hub/AgentSkills -s '*' -y
```

### 安装单个 Skill

```bash
npx skills add HK-hub/AgentSkills -s <skill-name>
```

示例：

```bash
npx skills add HK-hub/AgentSkills -s docx
npx skills add HK-hub/AgentSkills -s creating-mermaid-diagrams
```

### 列出仓库中可用的 Skills（不安装）

```bash
npx skills add HK-hub/AgentSkills --list
```
