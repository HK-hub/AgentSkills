# Page Editor

像 Figma 一样直接修改真实页面代码，精准有效地让 AI 懂你的设计。

一个基于浏览器的 HTML 页面可视化编辑器，用户在浏览器中完成样式/内容编辑，保存后输出结构化 JSON，供 AI Agent 自动回写到源码。

## 安装

一条命令，适配所有 AI 编码工具（CodeBuddy、Cursor、Claude Code、Codex 等）：

```bash
npx skills add mabeima/Pag-editor
```

## 功能特性

### 样式编辑
- 背景色 / 渐变色（Figma 风格颜色选择器，支持光谱、色相、透明度）
- 文字颜色、字号、字重
- 圆角、内边距、外边距、间距
- 宽度、高度、边框、阴影、透明度
- Flex 布局属性（方向、主轴对齐、交叉轴对齐、换行、间距）

### 内容编辑
- 双击行内编辑文字内容
- 图片 URL 替换（background-image 或 img src）
- 图片适配模式（cover / contain / original）

### 高级功能
- **配色方案库** — 自动提取 CSS 自定义属性（变量/Token）
- **伪状态编辑** — 编辑 :hover、:focus、:active 样式
- **一致性检测** — 保存时自动检测跨元素模式，建议批量修改
- **元素删除** — 从 DOM 中删除元素（可撤销）
- **多选对齐** — 选中多个元素并进行对齐操作
- **完整撤销/重做** — 支持最多 200 步，Cmd/Ctrl+Z / Cmd/Ctrl+Shift+Z

## 工作原理

采用**双进程架构**：

1. **服务进程**（后台常驻）— 启动编辑器 HTTP 服务，自动打开浏览器
2. **监听进程**（前台阻塞）— 等待用户保存，输出结构化 JSON 到 stdout

```
用户在浏览器编辑 → 点击保存 → 输出 JSON → Agent 回写源码 → 浏览器自动刷新
```

## 适用场景

- 用户对页面样式反复提修改需求，用语言描述效率低
- 需要精确调整颜色、间距、字号等视觉属性
- 想要所见即所得的编辑体验，同时保持代码可控

## 技术栈

- Node.js + Express（服务端）
- 原生 JavaScript（编辑器前端，零框架依赖）
- SSE（服务端推送，实现无感刷新）
